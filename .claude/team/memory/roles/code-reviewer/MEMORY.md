# Role memory — code-reviewer

Curated index. One line per learning; detail in `learnings/`.

- 2026-08-09 — **When a guard is rewritten onto a better abstraction, re-probe the NEW abstraction's own edges — the old defect class often survives one level deeper.** The `lint:deps` regex guard was correctly rebuilt as an AST parse, closing all 9 previously-probed violation forms. But `pushString` accepted only `StringLiteral`, so ``import(`@nms/bff`)`` — a valid, resolvable ESM specifier — produced no specifier and exited 0. 64 committed tests and 11 independent Jarvis probes all missed it because every one used a string literal. Lesson: after an abstraction swap, enumerate the NODE TYPES the new parser can hand you (StringLiteral / TemplateLiteral / BinaryExpression / Identifier), not just the source forms you thought of.
- 2026-08-09 — **"Cannot be statically evaluated" must be a violation, not a skip.** A guard's fail-closed invariant has to cover *unverifiable* input, not only *erroring* input. The rebuilt guard correctly reported unparseable and unreadable files as violations, then silently ignored a dynamic `import(someVar)` whose target it could not resolve — the one case where it had most clearly proved nothing. Ask of every guard: what inputs does it merely fail to understand, and does it announce them?
- 2026-08-09 — **Verify "fail-closed" fixes by making them fail, not by reading them.** Every inert-control fix this loop was confirmed by execution: four never-resolving `/ready` checks answered 503 in 210 ms; a typo'd `LIBRENMS_API_TOKKEN` was rejected; `/health` still returned 200 with all four dependency probes wired to `throw`; a route throwing SQL+bearer+paths returned only the safe envelope. Reading the code would have confirmed all of these equally well and proved none of them.
- 2026-08-09 — **A shared-reference DAG falsely reported as circular is a real regression risk in cycle-safety fixes.** Verify both directions: `{a: shared, b: shared}` must serialize fully while a true cycle yields `[Circular]`. The correct mechanism is a path-scoped `Set` with `finally { seen.delete(input) }` — a global `WeakSet` passes the cycle test and silently corrupts legitimate repeated structures.
- 2026-08-09 — **Write findings to `.claude/team/artifacts/<work-item>/` as a file before returning the message.** Iteration 1's reviewer report survived only because it reached the main thread; Jarvis's transcript copy was 0 bytes and 7 findings were nearly re-derived from a degraded reconstruction. The artifact file is the durable record.
