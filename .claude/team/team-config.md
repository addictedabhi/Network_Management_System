## 9. Test environment (RESOLVED at G1 — human decision on OQ-17)
- Verification uses **DUMMY POLLERS / simulated devices** rather than production hardware: simulators exposing **SNMP** and **TR-069** so the platform has something real to poll.
- **TR-069 is a new protocol dimension** not present in the architecture reference. LibreNMS is SNMP-centric; TR-069 (CWMP) is not a native LibreNMS collection protocol and likely implies a separate ACS component or an adapter feeding the system. This is an explicit DESIGN QUESTION for the Technical Architect (requirement doc OQ-21) — it must NOT be treated as silently in scope.
